# 📝 Exemple de Question à Copier dans Notion

## Comment utiliser ce template :

1. Créez une nouvelle page dans votre base de données Notion "Application TAGE MAGE"
2. Remplissez les propriétés (voir ci-dessous)
3. Copiez-collez les blocs de contenu dans la page

---

## ✏️ Propriétés de la page

Remplissez ces champs dans votre base de données :

| Propriété | Valeur |
|-----------|--------|
| **Question** | Trouvez les deux valeurs manquantes |
| **Catégorie** | Logique |
| **Difficulté** | medium |
| **Tags** | série double, logique numérique, logique alphabétique |
| **Favoris** | ☐ (cochez si vous voulez) |

---

## 📊 Contenu de la page

### Bloc 1 : Callout Série Horizontale

**Instructions :**
- Créez un bloc **Callout**
- Ajoutez l'emoji : ➡️
- Changez la couleur de fond en **Bleu** (optionnel)
- Collez le texte ci-dessous :

```
SÉRIE HORIZONTALE
Label: Série alphabétique
A | B | ? | D | E
```

---

### Bloc 2 : Callout Série Verticale

**Instructions :**
- Créez un bloc **Callout**
- Ajoutez l'emoji : ⬇️
- Changez la couleur de fond en **Vert** (optionnel)
- Collez le texte ci-dessous :

```
SÉRIE VERTICALE
Label: Série numérique +3
5 | 8 | 11 | ? | 17
```

---

### Bloc 3 : Espace (paragraphe vide)

Ajoutez un paragraphe vide pour séparer.

---

### Bloc 4 : Options de réponse (To-do)

Créez 4 blocs **To-do** avec ces textes :

- [ ] C et 14
- [x] **C et 13** ← Cochez cette case (bonne réponse)
- [ ] D et 14
- [ ] B et 13

---

### Bloc 5 : Espace (paragraphe vide)

Ajoutez un paragraphe vide pour séparer.

---

### Bloc 6 : Explication

**Instructions :**
- Créez un bloc **Heading 3** avec le texte "Explication"
- Créez un paragraphe en dessous avec l'explication

```
Explication
```

```
La série horizontale suit l'ordre alphabétique : A, B, C, D, E. La valeur manquante est donc C.

La série verticale est une suite arithmétique avec une raison de +3 : 5, 8 (+3), 11 (+3), 14 (+3), 17 (+3). La valeur manquante est 14.

Réponse : C et 13
```

## ⚠️ Points importants

### Format obligatoire :

1. **Première ligne du callout** : Doit contenir exactement "SÉRIE HORIZONTALE" ou "SÉRIE VERTICALE"
2. **Séparateur** : Utilisez ` | ` (espace-pipe-espace) entre les éléments
3. **Emoji** : ➡️ pour horizontal, ⬇️ pour vertical (recommandé mais pas obligatoire)
4. **To-do cochée** : Marquez la bonne réponse en cochant la case

### Flexibilité :

- ✅ Le `?` peut être à **n'importe quelle position**
- ✅ Le nombre d'éléments peut varier (minimum 2)
- ✅ Les labels sont **optionnels**
- ✅ L'explication est **optionnelle**
