# Guide : Séries Doubles (Sous-test 6 TAGE MAGE)

## 📚 Comment ajouter une série double dans Notion

### 1. Créer une nouvelle page dans votre base de données

**Propriétés à remplir :**
- **Question** (titre) : "Trouvez les deux valeurs manquantes" ou votre texte de question
- **Catégorie** : "Logique" ou "Sous-test 6"
- **Difficulté** : easy, medium ou hard
- **Tags** : série double, logique numérique, logique alphabétique, etc.
- **Favoris** : Cocher si vous voulez marquer cette question

### 2. Ajouter le contenu de la page

#### a) Premier bloc Callout - Série Horizontale

Créez un bloc **Callout** avec :
- **Emoji** : ➡️ (flèche droite)
- **Couleur de fond** : Bleu (optionnel mais recommandé)
- **Contenu** :
```
SÉRIE HORIZONTALE
Label: Série alphabétique
A | B | ? | D | E
```

**Format important :**
- Première ligne : `SÉRIE HORIZONTALE` (obligatoire)
- Deuxième ligne : `Label: [votre description]` (optionnel)
- Troisième ligne : Les éléments séparés par ` | ` (espace-pipe-espace)
- Utilisez `?` pour marquer la valeur inconnue (n'importe où dans la série)

#### b) Deuxième bloc Callout - Série Verticale

Créez un second bloc **Callout** avec :
- **Emoji** : ⬇️ (flèche bas)
- **Couleur de fond** : Vert (optionnel mais recommandé)
- **Contenu** :
```
SÉRIE VERTICALE
Label: Série numérique
5 | 8 | 11 | ? | 17
```

#### c) Options de réponse (blocs To-do)

Ajoutez vos options de réponse sous forme de blocs **To-do** :

```
☐ C et 14
☑ C et 13  (cochez la bonne réponse)
☐ D et 14
☐ B et 13
```

**Important** : Chaque option doit contenir les deux valeurs (une pour chaque série).

#### d) Explication (optionnel)

Ajoutez un titre **Heading 3** "Explication" suivi d'un paragraphe expliquant la logique :

```
### Explication

La série horizontale suit la suite alphabétique : A, B, C, D, E
La série verticale suit la suite +3 : 5, 8, 11, 14, 17
```

## 💻 Comment ajouter une série double dans l'application

### 1. Accédez au formulaire d'ajout

Dans l'application, cliquez sur "Ajouter des questions".

### 2. Sélectionnez le type de question

Dans le premier menu déroulant **"Type de question"**, sélectionnez :
```
Série Double (Sous-test 6)
```

### 3. Remplissez les champs standards

- **Catégorie** : Logique, Sous-test 6, etc.
- **Difficulté** : Facile / Moyen / Difficile
- **Question** : "Trouvez les deux valeurs manquantes"

### 4. Configurez la série horizontale

**Série Horizontale ➡️**

1. **Label** (optionnel) : "Série alphabétique"
2. **Éléments** : Remplissez les cases avec vos valeurs
   - Exemple : A, B, C, D, E
3. **Marquer l'inconnue** : Cliquez sur le bouton **?** à côté de la case que vous voulez marquer
   - La case devient bleue et affiche un grand **?**
   - Vous pouvez placer le **?** n'importe où (pas forcément à la fin)
4. **Ajouter/Supprimer** : Utilisez les boutons + et X pour gérer le nombre d'éléments

### 5. Configurez la série verticale

**Série Verticale ⬇️**

Même procédure que pour la série horizontale :
1. **Label** (optionnel) : "Série numérique"
2. **Éléments** : 5, 8, 11, 14, 17
3. **Marquer l'inconnue** : Cliquez sur le bouton **?** correspondant

### 6. Aperçu en temps réel

En bas du formulaire, vous verrez un aperçu de votre matrice avec les deux séries affichées.

### 7. Options de réponse

Remplissez les options en indiquant les paires de valeurs :
- ☐ C et 14
- ☑ C et 13 (cochez celle-ci)
- ☐ D et 14
- ☐ B et 13

### 8. Explication (optionnel)

Ajoutez une explication de la logique des séries.

### 9. Enregistrer

Cliquez sur **"Ajouter la question"** pour sauvegarder dans Notion.

## 🎯 Exemples de séries doubles

### Exemple 1 : Alphabétique + Numérique

**Série horizontale :**
```
A | B | ? | D | E
```
Logique : Suite alphabétique

**Série verticale :**
```
3 | 6 | 9 | ? | 15
```
Logique : +3

**Réponse :** C et 12

### Exemple 2 : Inconnues au milieu

**Série horizontale :**
```
2 | 4 | ? | 16 | 32
```
Logique : ×2

**Série verticale :**
```
Z | Y | X | ? | V
```
Logique : Alphabet inversé

**Réponse :** 8 et W

### Exemple 3 : Logiques complexes

**Série horizontale :**
```
1 | 1 | 2 | 3 | ?
```
Logique : Suite de Fibonacci

**Série verticale :**
```
? | 4 | 9 | 16 | 25
```
Logique : Carrés parfaits

**Réponse :** 5 et 1

## ⚠️ Points importants

### Dans Notion :
- ✅ Utilisez bien les émojis ➡️ et ⬇️
- ✅ Respectez le format avec ` | ` (espace-pipe-espace)
- ✅ La ligne doit commencer par "SÉRIE HORIZONTALE" ou "SÉRIE VERTICALE"
- ✅ Le `?` peut être à n'importe quelle position
- ✅ Cochez la bonne réponse dans les options To-do

### Dans l'application :
- ✅ Cliquez sur le bouton **?** pour marquer une case comme inconnue
- ✅ Vous ne pouvez avoir qu'un seul **?** par série
- ✅ Cliquer à nouveau sur le bouton **?** permet de le désactiver
- ✅ L'aperçu vous montre en temps réel votre matrice

---

## 🔄 Synchronisation Notion ↔ Application

Toute modification dans Notion sera automatiquement visible dans l'application au prochain rechargement des questions. De même, toute création/modification via l'application sera stockée dans Notion et éditable directement depuis votre base de données.

## 📸 Affichage pendant les sessions

Pendant les sessions d'entraînement ou d'examen, les séries doubles s'affichent avec :
- **Cadre bleu** pour la série horizontale
- **Cadre vert** pour la série verticale
- **Animation pulsante** sur les valeurs manquantes (?)
- **Instructions** claires pour l'utilisateur
